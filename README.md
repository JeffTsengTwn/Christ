# 基督傳之人子

四福音書裡的一生。像素風格的網頁小遊戲：從伯利恆走到各各他，再到七日頭一日的空墳墓，與加利利的山。每一章你扮演這段記載裡該在場的那個人，把經上的話走完。

畫面為 320×192，依視窗整數放大。中文經文引自和合本；英文是為本遊戲譯出的對應文字。本遊戲依據四福音書而作，並不取代聖經本身。

## 開發

需要 Node.js。

```bash
npm install
npm run dev
```

開發伺服器預設開在 [http://localhost:5173](http://localhost:5173)。若埠被占用，Vite 會改用下一個可用埠。

```bash
npm run build    # 輸出到 dist/
npm run preview  # 預覽建置結果
npm run deploy   # 推上 main，並等候 GitHub Pages 部署完成
```

部署前，到倉庫 **Settings → Pages**，將 Source 設為 **GitHub Actions**。完成後的網址是 [https://jefftsengtwn.github.io/Christ/](https://jefftsengtwn.github.io/Christ/)。

## 操作

| 動作 | 鍵盤 | 觸控 |
| --- | --- | --- |
| 移動 | 方向鍵或 WASD | 左下方向墊 |
| 交談、繼續對話、確認畫面 | 空白鍵、E 或 Enter | 「交談」，或點對話框 |
| 經文手札 | J，或右上「經文」 | 同左 |
| 靜音 | M，或右上「靜音」 | 同左 |
| 暫停 | Esc | — |
| 語言 | — | 右上「EN」或「中文」，標題畫面也有同一顆按鈕 |

粗指標裝置（手機、平板）會顯示方向墊與交談鈕。靜音狀態存在瀏覽器的 `localStorage`（鍵名 `follow-mute`），語言存在 `follow-lang`。系統若開啟「減少動態效果」，粒子與畫面震動會略過。

部分篇章會自己往前走，你主要把話說完。其餘篇章要自己走到人面前交談，或依畫面下方的目標行動。走過的經文會收進手札，章末與結局可以再讀一次。

## 語言

介面、篇章標題、對白與經文共用同一組鍵。要改文字，編輯 `assets/dict.csv`（欄位 `key,zh,en`），再產生字典。這一步需要 Python 3；玩遊戲本身只需要 Node.js。

```bash
python3 scripts/gen_dict.py
```

腳本寫出 `src/dict.js`。執行時由 `src/lang.js` 的 `text(key)` 依目前語言取值。

## 專案結構

```
index.html          畫面骨架、介面樣式、觸控區
vite.config.js      開發伺服器（埠 5173）
assets/dict.csv     中英文字典（鍵、中文、英文）
assets/hagia-sophia-christ.jpg  開始畫面照片（CC0 1.0）
scripts/gen_dict.py 由 dict.csv 產生 src/dict.js
src/main.js         載入篇章並啟動
src/lang.js         語言切換，並以 text(key) 取字
src/dict.js         由字典產生的中英對照
src/chapters.js     經文、二十八章劇情與地圖
src/game.js         移動、對話、音樂、介面與繪製
src/render/pixi.js  以 PixiJS 承接像素繪製
```

地圖以字元格子組成（草地、路、水、牆、地板等），人物與道具以像素方塊畫出。背景音樂用 Web Audio 依篇章切換（平安、清晨、暴風、莊嚴、結局），沒有外部音檔。
